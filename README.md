## 🚀 Featured Project

### 🍳 AI Recipe Assistant
> *A full-stack AI-powered recipe app with voice-guided cooking, local LLM inference, and a RAG pipeline — no API keys, no cost, fully local.*

- 🧠 **RAG Pipeline** — Ollama + Qdrant + LangChain for context-aware answers
- 🎙️ **Voice Cooking Mode** — reads each step aloud with pause/resume controls
- ❓ **In-step Doubt Chat** — AI knows exactly which step you're on
- 🐳 **Fully Dockerized** — one `docker compose up` runs the entire stack

`React` `TypeScript` `Vite` `FastAPI` `LangChain` `Ollama` `Qdrant` `PostgreSQL` `Docker`
